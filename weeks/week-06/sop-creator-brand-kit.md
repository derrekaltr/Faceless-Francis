# SOP — Creator Brand Kit (Visual + Audio Identity Blueprint)

> Program week: 06 · Owner: account manager (per creator) + creative lead · Cadence: once per creator at onboarding (after Wk 3–5 docs exist); refresh quarterly or on any rebrand · Status: draft
> Fills gap in `weeks/week-06/gap-audit.md`. Destination: `altr-management/03-content-ops/organic-growth-program/`. Field structure derived from `foundation/analysis-2.11-brand-build.md` (lesson 2.11 Brand Blueprint, sections 4–5).

## Purpose

Every creator gets a written look-and-sound kit before content is shot at volume, so recognition is engineered instead of accidental: any frame passes the one-second test, any clip is recognizable by ear, and the whole team (shooters, editors, story planner) reproduces the same signature without the creator re-deciding anything.

## Trigger

New creator onboarding, after the persona doc (Wk 3), niche scorecard (Wk 4), and format portfolio/compass position (Wk 5) are in `profile.md`. Never before — audience and niche dictate aesthetics, and a kit built first gets rebuilt. Re-run on niche pivot, platform expansion, or a failed quarterly consistency audit.

## Procedure

Run as a 60–90 min session with the creator present. Fill the fields in order; every field gets a reference link to a creator (any industry) who does it well.

1. **Pull prerequisites** from `profile.md`: perfect-fan sentence + SCV (Wk 3), archetype (Wk 3), niche + sub-niche (Wk 4), locked formats + aspirational/attainable position (Wk 5). The kit must visibly serve all five.
2. **Visual kit — four fields:**
   - *Feature to emphasize* — 1–2 defining physical features, accentuated through styling and framing. Never the entire brand; respect platform skin-exposure limits (ban exposure, Wk 7).
   - *Wardrobe formula* — pieces, colors, silhouettes consistent with the archetype + one signature piece worn in every post. Anti-pattern to reject in session: outfit hodgepodge.
   - *Setting* — the default filming backdrop, chosen by the "empty frame" test: with the creator removed, the frame still announces the niche. Props and set dressing listed explicitly.
   - *Signature prop* — one repeatable object the frame becomes known for.
3. **Audio kit — three fields:**
   - *Voice* — tempo/pitch/energy to lean into, and which locked formats suit that voice (long monologues need a voice that carries them; work with the voice the creator has).
   - *Signature sound/phrase* — 1–3 candidates (catchphrase, recurring vocal pattern, or niche SFX kit — e.g., trade/hobby sounds that telegraph the niche). Editors get the SFX files.
   - *Music direction* — genre + a curated 10-track starter playlist reflective of the niche in-group. Trending audio is opt-in per post with a written reason it reinforces the brand; note that audio pulls its home geography (coordinate with account geography targets, ops appendix §3).
4. **Run the recognizability tests** and record results:
   - *One-second test:* cover the handle, show an outside viewer single frames from 9 recent posts for ~1s each — they must name who + niche.
   - *Across-the-room test:* play 3 clips audio-only — recognizable as this creator?
5. **Record + distribute:** write the kit into the brand-kit section of `profile.md`; shopping/prop list → `content-drop-automation` shoot planning; playlist + SFX kit → editors; signature elements → The Weekly Edit story planner so stories match reels.
6. **Internal — LLM handoff:** feed the completed `profile.md` (persona + brand kit) to the scripting LLM as persistent per-creator context ("write this in <creator>'s brand elements"), per ops appendix §4. Never delegate personality, edgy takes, slang, or comedy to the model; always a human pass.
7. **Monthly consistency audit** (piggyback on ReelCritic review): each post should use ≥2 visual kit elements and ≥1 audio element.

## Thresholds & kill criteria

| Condition | Action |
|---|---|
| One-second test: viewer IDs < 7 of 9 frames | Kit not locked — tighten wardrobe/setting repetition before scaling volume (Wk 8 gate) |
| Consistency audit: < 70% of posts use kit elements | Review with creator; check whether the uniform is impractical for her shoot reality |
| Creator breaks uniform two shoots running | Comfort/sustainability problem — revisit kit choices with her, don't just re-instruct |
| Trending audio used without written justification 3+ times/month | Flag to creative lead; playlist refresh session |
| Kit fights the niche (aesthetics contradict Wk 4 positioning) | Stop — re-run niche review before re-kitting |

## Tools

- `profile.md` (brand-kit section) — single source of truth per creator.
- Reference-link library — one exemplar creator per kit field, collected during the session.
- Shared playlist + SFX folder (Dropbox) — editors pull audio only from here by default.
- ReelCritic — carries the monthly brand-consistency check.

## Escalation

Creator rejects the uniform concept or can't sustain it after one revision cycle → Derrek, with the two kit versions and shoot notes. Kit/niche contradiction that survives a niche review → Derrek before any further content spend.

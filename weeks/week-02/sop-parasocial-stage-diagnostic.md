# SOP — Parasocial Stage Diagnostic

> Program week: 02 · Owner: account manager (per creator) · Cadence: monthly + before any funnel-debugging conversation · Status: draft
> Fills gap in `weeks/week-02/gap-audit.md`. Destination: `altr-management/03-content-ops/organic-growth-program/`.

## Purpose

Before anyone blames the funnel, the link, or the chat team for weak conversions, establish *which parasocial stage* the audience has actually reached — so the fix targets the real bottleneck.

## Trigger

Monthly per creator; mandatory whenever link clicks or OF conversions are flagged low (OF conversion floor: 0.1% of followers/week — Wk 8 SOP).

## Procedure

1. Sample the last 50–100 comments + a week of DMs on the main promo account.
2. Score the signals:
   - **Recognition** — emoji-only/shallow comments dominate; no name usage.
   - **Familiarity** — fans use the creator's name, reference jokes/formats; little emotional language; link clicks flat.
   - **Attachment** — personal disclosures ("this made my day", stories), rising DM volume, questions about the creator's life.
   - **Loyalty** — fans defend the creator against negative comments, share unprompted, recognizable regulars on every post.
3. Record the stage in the creator's profile (`profile.md`) with 2–3 pasted example comments as evidence.
4. Prescribe content one stage down the pipeline:
   - Stuck at recognition → consistency work: tighten niche + recognizable elements (Wk 1, Wk 6).
   - Stuck at familiarity (the classic stall) → attachment content: close-friends stories (The Weekly Edit), rituals, opinions, running jokes, reply-to-comments videos. No link pushes.
   - At attachment → loyalty content: community callbacks, regulars acknowledged, insider references.
   - At loyalty → monetization is permitted to be explicit; coordinate CTA cadence with the chat team.
5. Share the stage with the chat team — a fan at attachment is worked differently than one at loyalty (ops appendix §5).

## Thresholds & kill criteria

| Condition | Action |
|---|---|
| Stage unchanged 3 consecutive months | Escalate: content strategy review (format/compass fit, Wk 5) |
| High views + stuck at recognition 60+ days | Audience-match problem, not connection problem — run Wk 1 metrics + niche review first |
| Attachment+ but conversions still under floor | Now it's legitimately a funnel/chat problem — debug downstream |

## Tools

- Native comments/DM review (manual, 20 min/creator) · creator `profile.md` · The Weekly Edit for attachment-stage prescriptions.

## Escalation

Three months without stage movement, or disagreement between account manager and chat team on stage → Derrek, with the evidence comments attached.

# SOP — Format Portfolio (70/20/10) & Compass Quadrant Lock

> Program week: 05 · Owner: content lead · Cadence: weekly content planning + 2-week format test cycles · Status: draft
> Fills gap identified in `weeks/week-05/gap-audit.md`. Destination: `altr-management/03-content-ops/organic-growth-program/`.

## Purpose

Every promo account runs a deliberate content portfolio instead of ad-hoc posting: a named core format with VTFR history, a measured 70/20/10 mix, a disciplined test-and-promote cycle for new formats, and one Content Compass quadrant per creator that every post — core, filler, or experimental — must hit.

## Trigger

Weekly, during content planning for each account. Format test cycles start whenever an account has no named core format, or a retirement trigger fires. Quadrant lock is set once at creator onboarding (or at this program's rollout) and only changes by escalation.

## Procedure

1. **Lock the quadrant (once per creator).** With the account manager, pick the creator's compass position — X (value ↔ entertainment), Y (attainable ↔ aspirational) — plus the Z-axis signature emotion (one or two words, e.g. "cozy comfort", "playful superiority"). Record all three in the creator's `profile.md` next to the Wk 3 avatar/archetype fields. Share the quadrant + Z-emotion with the chat team so chat voice matches content voice (ops appendix §5; professional persona language only, per policy ruling #2).
2. **Bucket every planned post.** The weekly plan tags each post `core` / `filler` / `experiment`. Target split ≈ 70/20/10 — at 3 posts/day (21/week) that's roughly 15 core · 4 filler · 2 experiments; at 1/day, 5 · 1 · 1. Filler is batch-produced (text-over-B-roll via trial-reels-pipeline, niche-adapted trends); never let filler exceed core.
3. **Quadrant check at scheduling.** Before a post is queued: does it sit in the creator's locked quadrant and evoke the Z-emotion? Off-quadrant → rework or drop. Trends must be adapted into the niche *and* the quadrant or skipped.
4. **Test new formats on a fixed cadence.** Candidate formats are screened first on legibility / replicability / practicality (score 1–5 each; <10/15 → filler candidate at best, don't invest a test cycle). A candidate that passes gets posted daily for 2 weeks through the trial-reels variant machinery, then judged on the test posts' VTFR and AWT (Wk 1 definitions).
5. **Promote on the rule, not the vibe.** A format that holds **consistent ~0.5 VTFR across the test window** is promoted to core (or to the on-deck core if one exists). Record the promotion, with VTFR history, in the format tracker. Then ride it until it dies — don't dilute a working core with novelty.
6. **Retire on the numbers.** When a retirement trigger fires (table below): rotate hooks/variations within the core first (fatigue is often hook-level, not format-level — Wk 9); if decline continues one more cycle, promote the best-performing experiment and start a new test cycle.
7. **Log everything** in the format tracker: Account · Format name · Bucket · L/R/P score · Test dates · VTFR (test + trailing 30d) · Status (testing / core / on-deck / filler / retired).
8. **Analyze winners, iterate.** For each winning post, note the suspected driving elements (hook, topic, outfit, setting) in the creator's format notes; next batch recreates winners with slight variations.

## Thresholds & kill criteria

| Condition | Action |
|---|---|
| Format holds ~0.5 VTFR consistently over 2-week daily test | Promote to core |
| Experiment below benchmarks after 2-week test | Archive in tracker (keep the data); next experiment |
| Core VTFR declining 2+ consecutive weeks on unchanged content | Hook/variation rotation first; if decline continues, begin replacement test cycle |
| HPF = 0 for 30+ days (Wk 1 SOP) | Mandatory format/hook change — the portfolio is stale |
| Post drafted outside the locked quadrant | Pulled or reworked before scheduling — no exceptions |
| Weekly mix drifts past ~±10 pts from 70/20/10 | Correct next week's plan; note cause in tracker |
| No core format after 3 consecutive test cycles | Escalate — likely a niche/avatar problem (Wk 3–4), not a format problem |
| Output bar | 7/10 quality · 1–3 posts/day · carousels max 1/day |

## Tools

- **Trial Reels pipeline** (`altr-management/03-content-ops/trial-reels-pipeline/`) — daily base + 5–10 variants: runs both the filler bucket and format-test volume.
- **Format tracker sheet** — one row per format per account (net-new, columns in step 7).
- **Creator `profile.md`** — quadrant + Z-emotion of record.
- **Native insights / Metricool** — VTFR/AWT inputs; **ReelCritic** — per-Reel diagnosis referencing the named core format.

## Escalation

Quadrant changes are founder-level: a creator or manager wanting to reposition (e.g. attainable → aspirational) goes to Derrek with the VTFR history, because a quadrant switch resets the audience's brand expectations. Also escalate: no core after 3 test cycles, or content team and chat team disagreeing on the creator's quadrant in practice.
